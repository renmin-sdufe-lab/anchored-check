# Protocol: hypotheses, gates and readings fixed before each run

Every experiment in this repository was run against a written protocol: the
hypothesis, the numerical gate that would count as support, and the reading of
*both* outcomes were fixed before the corresponding sweep was started, and no
parameter was changed after a gate run to make a criterion pass. This file is
the record. Dates are the day the protocol was fixed. All runs use ten paired
seeds under common random numbers (DESIGN §7), `p = 0.2` targeted UEs, and
paired 95 % Student-t intervals over the seeds. Between revisions the apparatus
was audited line by line; where an audit changed the apparatus, the change is
named in the row that follows it, and the superseded run is not reinterpreted.

The frozen tables in `data/` are the confirmatory run `b1`, the majority-reach
run `b2` and the three diagnostics `diag_param`, `diag_veto` and
`diag_pingpong` below. The `b0` pilot is recorded for completeness and is not
reported in the article; revision `B2` was pre-registered and then replaced by
`B2′` before any of its runs were started. One superseded run is not shipped:
the first `diag_veto` sweep, which measured the check-set change alone and was
replaced by the rerun the same day, after the two residual reads of `N` were
closed.

**The hypothesis under test (H2).** Under common-cause telemetry poisoning,
where every executor reads the same falsified UE measurement report, a rule-diverse
decision layer fails at essentially the single-executor rate; an
observation-diverse layer with physical-consistency adjudication drives the
attack success rate low at a bounded false-positive rate on clean UEs and a
bounded measurement and compute cost; and the benefit shrinks as the attacker
reaches more channels, while channels rooted in the serving gNB's own uplink
measurement and in the operator's radio map are not reachable from the reporting
path (a stated assumption, argued rather than proven).

## Simplifications favourable to the defence

Three model choices favour the defended arms and were left in place so that the
results read as upper bounds.

- The serving gNB's own uplink measurement and the operator's radio map are
  assumed out of the attacker's reach. That is the assumption the whole
  mechanism rests on; it is stated in the article rather than proven, and the
  insider case is out of scope.
- The warm-up window is assumed clean, so every threshold is calibrated on
  unpoisoned data. An attacker present during calibration is not modelled.
- Position error behind the radio map is folded into `σ_map` rather than
  modelled separately, so the map's error is a single well-behaved parameter
  the sweep can move.

One measured quantity runs the other way and is reported rather than corrected:
the attacker's opportunities depend on each arm's own serving assignment, so the
actionable share differs across arms and is printed beside every rate.
